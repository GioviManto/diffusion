% Three environments, deliberately unequal in weight.
%
% `intuition' is NOT a box. An earlier version of this document set it as a coloured panel,
% which put a decorated frame on nearly every page and made a technical supplement read like a
% textbook. It is now an ordinary indented paragraph: the content is worth keeping, the
% packaging was not.
%
% `pitfall' and `codebox' remain boxed, because both interrupt the argument on purpose -- one
% states an assumption that is doing real work and what fails without it, the other pins a
% mathematical object to the line of code that realises it. Neither should be used for
% commentary that the surrounding prose already carries.
\newenvironment{intuition}%
  {\par\smallskip\begingroup\leftskip=1.2em\rightskip=1.2em\small\noindent\ignorespaces}%
  {\par\endgroup\smallskip}
\newtcolorbox{pitfall}[1][]{breakable, colback=black!2, colframe=black!45,
  boxrule=0.5pt, left=6pt, right=6pt, top=5pt, bottom=5pt,
  title=\textbf{Assumption at work}, fonttitle=\small\bfseries, #1}
\newtcolorbox{codebox}[1][]{breakable, colback=black!3, colframe=black!25,
  boxrule=0.5pt, left=6pt, right=6pt, top=5pt, bottom=5pt,
  title=\textbf{Implementation}, fonttitle=\small\bfseries, #1}

\textbf{Who this is for.} A reader who knows undergraduate probability and linear algebra and
nothing about diffusion models, graphical models, or expectation maximisation. Every concept
used anywhere in the project is built here from its definition. Nothing is cited in place of
an explanation. Where a step is standard but non-obvious, it is done in full rather than
asserted, and where an assumption is doing real work, there is a box saying what breaks
without it.
