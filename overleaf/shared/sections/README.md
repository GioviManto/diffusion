# sections — shared LaTeX blocks

and `efficiency-numbers.tex` are GENERATED by
`research/nongaussian-bp/tools/make_tab_efficiency.py` — do not hand-edit them.

`check_paper.sh` fails if a file here is inputted by neither the paper nor the
workshop, because an unreachable copy drifts and then gets pasted back in.
