# figures — every figure, shared

Written by `research/nongaussian-bp/tools/make_figures.py`. Both `.pdf` (used by
LaTeX) and `.png` (for quick viewing); only the PDFs are included.

One directory for all four documents, so two of them cannot render different
pictures under the same name. Do not add a figure by hand — add it to the
generator, or it will vanish on the next run.
