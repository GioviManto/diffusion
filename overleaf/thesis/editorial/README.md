Working notes about the thesis as a document rather than about the science:
what changed between drafts, which figures exist and where they come from,
decisions taken about structure, and the correctness checklist.

## These four files were restored from git history and may be stale

They were listed in `.gitignore`, so git never tracked their later edits. During
the 18 Aug 2026 restructuring the old `thesis/` tree was removed with `rm -rf`,
which took the untracked working copies with it. What is here was recovered from
commit `2fbdd53` (21 July 2026, 176 commits before the removal).

**Anything written into these files between 21 July and 18 August is gone.** If
you remember making notes here in that window, they need rewriting. The science
is unaffected — nothing in these files feeds a document or an experiment.

Also lost, and not recoverable from history because it was never tracked:
`thesis/official-guides/` held Bocconi's two thesis-submission PDFs
(`Guida_tesi_LM_ENG_*.pdf` and `guide.pdf`). Both are downloadable again from the
Bocconi site; they are reference material, not project output. If you re-download
them, put them in `Diffusion/sources/official-guides/`.

They are now tracked, so this cannot happen to them again.
