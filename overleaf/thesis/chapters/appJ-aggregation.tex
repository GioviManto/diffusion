\chapter{How the Reported Ratios Were Aggregated}\label{app:aggregation-chapter}

A ratio is a nonlinear function of two means, so it depends on the order in
which the averaging is done: $\E[X]/\E[Y]$ is not $\E[X/Y]$, and the gap
between them grows with the spread. Both ratios this thesis reports therefore
need the same question asked of them --- whether the number is a property of
the estimator or of the estimand chosen to summarise it. Neither section
below refits anything; both recompute the same frozen cells under alternative
aggregations.

\section{The unstructured comparison}

The ratio quoted in Section~\ref{sec:em-pointwise} and in the conclusions is one
of several summaries the same cells support, and it is systematically the
largest of them. That is a fact about the estimand rather than about the
estimator, so it belongs with the number wherever the number appears. The
section below is generated by
