# BP Markov Diffusion Gaussian Approximation Package

This folder contains the report, source, notebook, script, and outputs for the generalization from Gaussian AR(1) BP to general Markov-chain diffusion scores.

## Main files

- `report/bp_markov_diffusion_gaussian_approx.pdf`: full report with derivations, algorithms, experiment design, plots, and code explanation.
- `report/bp_markov_diffusion_gaussian_approx.tex`: LaTeX source for the report.
- `code/bp_general_markov_diffusion_experiments.py`: Python script implementing the experiments.
- `code/bp_general_markov_diffusion_experiments.ipynb`: notebook that loads the outputs and explains/reruns the experiment pipeline.
- `outputs/`: CSV files and figures generated by the report run.

## Reproduce the report experiment

From this package folder:

```bash
python code/bp_general_markov_diffusion_experiments.py --mode report --n-trials 12 --output-dir outputs_reproduced
```

For a fast smoke test:

```bash
python code/bp_general_markov_diffusion_experiments.py --mode quick --output-dir outputs_quick
```

## Core idea

For Markov-chain clean priors under coordinatewise OU noising, the posterior remains a chain. BP is exact on this tree structure. The diffusion score is recovered from the posterior mean:

```text
s_i(x,t) = -(x_i - alpha_t E[a_i | x]) / Delta_t.
```

In continuous non-Gaussian chains, exact BP messages are functions, so they must be represented approximately. The experiments compare reference grid BP with Gaussian projected BP and validate the grid using the Gaussian AR(1) precision-matrix score.
