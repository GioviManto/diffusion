Belief Propagation for Diffusion Scores on Markov Chains

Exact Gaussian AR(1) baseline, and the measured cost of Gaussian message closure on general Markov chains.

Giovanni Mantovani · GitHub repository

The clean signal is a Markov chain a₁:ₙ, observed through coordinatewise Ornstein–Uhlenbeck noising at diffusion time t > 0. On a chain, sum-product belief propagation (BP) computes the exact posterior, and the diffusion score follows from the posterior denoiser:

si(x,t) = ∂xi log pt(x) = −(xi − αt mi(x,t)) / Δt,    mi(x,t) = E[ai | x₁:ₙ]

Exactness is never the issue—the issue is representation: for a continuous non-Gaussian chain, each BP message is a whole function. This project first nails the exactly solvable Gaussian case, then measures the error introduced by forcing BP messages back into the Gaussian family (Gaussian/AMP-style closure) on a non-Gaussian test chain.
