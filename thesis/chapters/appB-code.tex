are dependency-light Python (NumPy/SciPy only), and every figure and
numerical claim of Chapters~\ref{ch:gaussian}--\ref{ch:bp} is generated by
these modules together with the audit drivers described in
Appendix~\ref{app:repro}. The full repository layout is given there.
